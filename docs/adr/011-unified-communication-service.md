# ADR-011 — Unified Communication Service

Approved PR #25 C.3 variant B. Reuse existing ConnectionDefinition/TransportConfig/ConnectionLease and CommunicationService. Typed network modes cover TCP MBAP, TCP RTU, TCP TLS (MBAP only), UDP MBAP and UDP RTU; SerialMode covers RTU/ASCII. Default TCP opening timeout 2000 ms independent of response timeout; unit ID, retries, function, span and priority are request attributes. TLS never silently downgraded. Per-attempt generated MBAP ID, validated using same context; 16-bit wrap is inherent, one active transaction per resource, reconnect after invalid response. Caller authorization remains mandatory; no automatic write/raw replay.

Raw must acquire exclusive physical resource, retire quiescent idle cache atomically, reject active/pinned owner. Monitor transport migration only, existing sequential scheduler retained until B.3. WRR 3:2:1, 128 waiting, reserve 8 for manual. Separate measured RTT, queue wait, connection, recovery and acquisition; missing values null. Scoped Stop synchronizes logical TX admission after reset; after admission bounded active TX/RX completes. Central shutdown must stop admission and producers before closing workers. IP-range discovery remains transient/bounded, fixed devices persistent. Preserve Quiet Mode and previous safety policies. Windows-first CI and Windows QA; full cross-platform validation at final stage. See [contract](../CROSS_TOOL_INTEGRATION.md). No merge until review.
