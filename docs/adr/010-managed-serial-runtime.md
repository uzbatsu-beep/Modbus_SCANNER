# ADR-010 — Managed Serial Runtime

Approved PR #22 C.2 variant B. Exclusive autodiscovery must refuse actively leased/pinned resources, but retire a quiescent automatic cache entry without waiting for idle timeout. Reserve the physical key atomically under the existing registry lock before marking the old worker stopping; retain reservation until join, including cancellation of acquisition. Exclusive session owns one generation at a time; switching settings joins the old worker and keeps the reservation and resource recovery deadline. Identical settings reuse the worker. Stop cancels the session, never dispatches new work, and allows active I/O to finish within existing bounds. Normal compatible leases remain the default for fixed configuration tools. See [SERIAL_MIGRATION](../SERIAL_MIGRATION.md) for approved diagnostics, criteria and remaining stages. C.2.1 is foundation only; no physical acceptance or merge before review.
